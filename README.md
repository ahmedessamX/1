# GitHub Account Consolidation

This repository contains documentation and guidance for consolidating multiple GitHub accounts and email addresses into a single primary account.

## 📖 Documentation

See [ACCOUNT_MERGE_GUIDE.md](ACCOUNT_MERGE_GUIDE.md) for a comprehensive guide on:

- Transferring repositories between accounts
- Managing multiple email addresses in one account
- Migrating your GitHub activity
- Step-by-step consolidation process
- Important considerations and limitations

## Quick Summary

GitHub does not support direct account merging, but you can:

1. **Add all email addresses** to your primary GitHub account
2. **Transfer repositories** from your secondary account to your primary account
3. **Update Git configuration** to use your primary email
4. **Archive or delete** your secondary account when ready

For detailed instructions, please refer to the [Account Merge Guide](ACCOUNT_MERGE_GUIDE.md).
